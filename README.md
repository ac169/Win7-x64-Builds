# FFmpeg-Builds-Legacy

Based on BtbN/FFmpeg-Builds (autobuild-2025-07-31-14-15), perform compatibility processing for Windows 7 x64.

Notes:
1. Builds with the "nonfree" label are for development and testing purposes only.
2. Due to compatibility issues with the new version of SDL2 on Windows 7, it is recommended to set the environment variable SDL_AUDIODRIVER=directsound to ensure normal operation.
